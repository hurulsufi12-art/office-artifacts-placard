Entry for the [Office Artifacts: The One-Line Placard](https://make.fun/bounty/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2) bounty on make.fun.

`main.py` (Python stdlib only, deterministic, no network) renders one museum placard line for an ordinary office object and writes it to `/output/entry.txt`:

> Stapler, c. 1998, pressed steel. Ritual binding device of the open-plan temple; priests pressed it twice to seal a scroll forever. Gift of the Department of Unread Memos.

170 characters (gate: 1–180). Run with `python3 -P -s main.py`.
